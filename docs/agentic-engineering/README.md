## 2. Open Questions, Architectural Decisions & External Blockers (Deliverable 8)

### 2.1 Architectural Ambiguities Resolved by This Plan

1. **Dual Frontend / BFF Split-Brain (`apps/web` vs `apps/portal` + `services/control-plane`)**:
   - **Resolution (`OC-BG-023`, `OC-BG-026`, `OC-BG-027`, `OC-BG-033`, `OC-BG-042`, `OC-BG-044`, PRs #47, #49, #50, #53, #55)**: `packages/server` remains the single source of domain and persistence truth for projects, classifiers, decision services, evidence, and evolution, while `services/control-plane` owns multi-tenant identity, workspaces, API keys, and RBAC headers (`X-OpenClass-Workspace-Id`, `X-OpenClass-Actor`). In **PR #53**, `@openclass/sdk` was extended with `OpenClassControlClient` and `ControlApiError`, `apps/portal/src/api.ts` was migrated 100% onto `@openclass/sdk` (enforced by `test_portal_uses_sdk_without_raw_fetch`), and `services/control-plane` reconciles engine-created projects (`control_projects` ↔ `projects`). In **PR #55**, migration `0027_workspace_isolation_and_checkpoint_claims.py` added `workspace_id` to `projects` and enforced end-to-end engine & control-plane workspace ownership with explicit legacy claiming (`POST /api/v1/projects/{id}/claim`). Because both `apps/web` and `apps/portal` remain active (`apps/web` is not retired), `OC-BG-027` is marked **`PARTIAL`** under its original scope.
2. **Candidate, Evaluation, Checkpoint & Promotion Governance (`0017`..`0027`, PRs #37–#38, #52, #54, #55)**:
   - **Resolution (`OC-BG-010`..`014`, `OC-BG-035`, `OC-BG-040`, `OC-BG-044`, PRs #37–#38, #52, #54, #55)**: Durable multi-node execution checkpoints (`0026_decision_run_checkpoints.py`), supervision pause gates, operator permission checks (`403`), atomic compare-and-swap checkpoint claiming (`0027_workspace_isolation_and_checkpoint_claims.py` with stale-claim crash recovery and lifecycle-based cancellation after pause), version conflict detection (`409`) + pinned snapshot execution, and genuine downstream graph execution via `DecisionExecutor.resume` were completed across **PR #52** and **PR #55** (`OC-BG-035` and `OC-BG-044` **`VERIFIED`**). Strictly disjoint discovery/dev/regression/holdout datasets (`assert_strictly_disjoint_datasets`), server-side discovery-to-holdout leakage rejection (`409`), `label_source="prediction"` rejection (`422`), choice/alias collision rejection (`409`), regressive candidate rejection (`regressions > 0`), and both offline mechanism tests and live Vercel AI Gateway (`OPENCLASS_RUN_LIVE_TESTS=1`) end-to-end closed-loop evolution proofs were completed on Tracks 2 and 3 (`OC-BG-011` and `OC-BG-040` **`VERIFIED`**), while legacy Track 1 (`POST /api/v1/classifiers/{slug}/candidates`) remains intentionally fail-closed (`409`).
