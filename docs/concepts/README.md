# Concepts

**UNKNOWN is a state, not a class.** It means the current ontology cannot confidently
explain an observation. A likely_novel assessment is evidence, not authorization
to create a class. Ambiguous known classes can also lead to abstention.

**Ontology versions are immutable.** Stable class IDs identify concepts across
versions. Definitions, aliases and examples that influence a result must be captured
in its version. Historical runs keep their original version reference.

**Discovery is a proposal process.** Evidence grows before discovery/canonicalization,
then evaluation and human review precede activation. Ground truth must be verified
independently of model predictions.
