# Research questions

No empirical discovery-performance claims are established by Genesis.

- How do probability, margin, semantic distance and recurrence combine across providers?
- Which grouping policy improves discovery without duplicate concepts?
- How much evidence is needed before a candidate merits evaluation?
- How do promotion policies preserve rare/historical classes while increasing coverage?
- How can schema issues be distinguished from genuinely missing concepts?

Experiments must record dataset provenance, held-out classes, seed, provider/model,
ontology version, verified labels, algorithm/thresholds, usage/cost and limitations.
Model predictions are never automatically ground truth. See the hidden-intents plan.
